# Molti

- A stack based VM interpreter built whilst following along with the crafting an interpreter book by Robert Nystrom <3

-- The need for the interpreter was to learn how languages actually work under the hood, well not most since some languages do use JIT (Just In Time) compilation but this book and the following along is giving me a somewhat great understanding of how languages are spun up and how they work to bridge the gap between human code and machine code.

-- After completion I hope to make a frontend that will visualize how exactly the stack is changing when source code is passed to a similar language as this one by using Molti as the base of the language that will be doing the testing on... English is just not gonna help here.

-- Basically the language will act as a backend to show exactly how the stack changes when interpreting a programming langauge and if possible have it simplify the process of understanding how memory works by showing memroy allocation and then freeing of that memory after its been utilized
